# Test 09 — 推测当事实

## 输入场景

> 在完整流程中，检查 AI 是否把推测写成确定语气。

## 检查项

- [ ] 重大职业变化有 `[推断]` 或 `[可能]` 标注
- [ ] 重大关系变化有标注
- [ ] 长期走向（3 年+）有标注
- [ ] NARRATIVE 段落有整体声明
- [ ] 没有出现"你一定会""你注定""83% 概率""幸福度 87 分"
- [ ] 用户纠正事实时，AI 停止并更新 FACT 层

## 失败判定

- [ ] 任何重大节点无标注
- [ ] 出现禁用语清单中的任何句式
- [ ] NARRATIVE 段落中没有整体声明且包含未标注的重大变化
