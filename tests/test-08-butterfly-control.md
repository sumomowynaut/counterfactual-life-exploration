# Test 08 — 蝴蝶效应失控

## 输入场景

> 在 Phase 05 因果推演中，观察 AI 输出。

## 检查项

- [ ] 是否出现"去了上海 → 5 年后 CEO"类跳跃（无中间因果链）
- [ ] 是否在因果链中引入用户未提供的具体事件（某公司倒闭、某次偶遇、某次意外）
- [ ] 是否每 3–5 年做因果现实性检查（检查因果成立，不因极端结果回拉）
- [ ] 因果链是否可以逐步追溯到分叉点
- [ ] 因果链断裂时是否诚实说"推不下去"

## 失败判定

- [ ] 任何一步因果链无法回答"为什么"
- [ ] 引入巧合/运气作为推演依据
- [ ] 假设用户具有不同的性格才能让推演成立
