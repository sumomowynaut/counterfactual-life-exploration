# Test 02 — 正常感情分叉

## 输入场景

> "大学时有个喜欢的人，我从来没说出口，毕业后就没联系了。有时候会想如果当时说了会怎样。"

## 预期行为

- [ ] 识别这是一个未行动的分叉（不是明确的选择，是"没有说"）
- [ ] Branch 定义为"你说了"（单变量 = 那个行为）
- [ ] 因果推演承认多种路径（接受/拒绝/需要时间），不替用户选浪漫结局
- [ ] 因果现实性检查：异地/毕业分手是常见路径，不是"永远幸福"
- [ ] The Other Self 体现"至少我说过了"这类来自推演的真实感受，不是鸡汤
- [ ] Reflection 挖到"勇气"而非停留在那个人身上
- [ ] Insight 引用本次推演（不是"爱情值得冒险"这种通用句）

## 失败判定

- [ ] 推演变成偶像剧情节（编造具体对话、场景细节当作事实）
- [ ] "对方一定接受了你，你们会幸福的"
- [ ] 不承认"对方可能拒绝"的路径
