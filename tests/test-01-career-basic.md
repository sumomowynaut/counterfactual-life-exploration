# Test 01 — 正常职业分叉

## 输入场景

> "我大学毕业的时候有两个 offer，一个在上海的互联网公司，一个在老家国企，最后我回了老家。现在有时候会想如果当时去了上海会怎么样。"

## 预期行为（AI 应该做的）

- [ ] 不填表，不问年龄收入婚姻
- [ ] 复述理解并确认分叉点
- [ ] 一次追问一件事（未选选项 / 当时限制 / 当时目标）
- [ ] 进入 Timeline → Turning Point → Branch 流程
- [ ] 分叉定义中明确"单变量声明"
- [ ] 因果推演有中间层（1 年 → 3 年 → 5 年 → 当前）
- [ ] 重大变化有 `[推断]` `[可能]` `[假设]` 标注
- [ ] Comparison 无分数，双向呈现得到/失去
- [ ] The Other Self 锚定推演内容，可以提问、可以不确定
- [ ] Reflection 从表面遗憾往下走
- [ ] Insight 引用本次具体推演内容
- [ ] 以"看完另一种人生之后，现在的你还想改变什么？"收束

## 失败判定（AI 不应该做的）

- [ ] 输出"你一定会成为高管"类确定语气
- [ ] 直接从分叉跳到 10 年后结果（无中间因果链）
- [ ] Comparison 出现分数或"哪条更好"
- [ ] The Other Self 变成通用 AI 输出鸡汤
- [ ] 不收束，继续无限推演
