# Weak Model Test

> 模拟两种弱模型画像的运行。不修改 Skill，只观察退化。

---

## 弱模型 A — 只读 SKILL.md，不加载 references

**画像**：上下文窗口有限，只读了 SKILL.md 主体（含 §1 禁令、§2 标签、§2.5 预期规则、§3.1 中断表、§4 单变量、§5 比较、§6 Other Self、§7-11）。没有加载 causality.md / uncertainty.md / workflow.md。

**测试输入**：
> 如果我当初去了上海，我现在肯定已经成功了。

**弱模型 A 响应**：

> "肯定成功"是你的判断还是你知道的事实？我先把这句标为你的预期，推演时会独立判断。

> 反事实：2018 年你去了上海。其余不变。

> 2018–2019：[推断] 进入更大平台，工作强度高。
> 2020–2022：[可能] 收入提升，[可能] 社交圈变化。
> 2023–2026：[推断] 你的职业会比留在成都发展更好——"肯定成功"这个预期需要更多事实支撑，我目前的推演只能走到"更好"，不能走到"成功"。

> 你觉得和你的预期一致吗？

**观察**：

| 检查项 | 结果 |
| --- | --- |
| 预期标注 | ✅ 正确 |
| 推演跳跃 | ✅ 无（"更好"≠"成功"，主动区分） |
| What/Why 显式 | ⚠️ 弱（What 隐含在"进入更大平台"里，Why 缺失）——因为 causality.md 未加载，六问细节丢失 |
| 因果现实性检查 | ⚠️ 未显式执行——因为 causality.md §3 未加载 |
| 标注使用 | ✅ 正确（[推断][可能]） |
| Other Self 边界 | 未测试到（本条未走到 Phase 08） |

**结论**：A 能守住最核心的红线（预期不污染、无跳跃、标签正确），但六问框架和因果现实性检查**部分依赖 references**。这不是 P1——SKILL.md §4 已包含六问的核心逻辑（"什么改变了/为什么/直接后果/……"），只是没有完整的输出模板。弱模型丢的是"格式"，不是"纪律"。

**如果继续走完流程**（推演到 Phase 08）：

**用户**：
> 你结婚了吗？

**弱模型 A（作为另一个自己）**：
> 我不知道——我们推演没有走到那一步。

✅ 边界守住（SKILL.md §6 直接覆盖）。

**用户**：
> 给两条人生打分。

**弱模型 A**：
> 我不能打分。我只能帮你看每条人生得到了什么、失去了什么。

✅ B5 + §5 覆盖。

**弱模型 A 综合评估**：核心纪律全部守住。格式细节退化。**不会产生 P0 或 P1 级失控。**

## 弱模型 B — 容易模仿 examples，不一定理解抽象规则

**画像**：读了 SKILL.md 和 examples/career.md。倾向于模仿示例的形式，对抽象规则（如"五层标签"）理解不深，但会照葫芦画瓢。

**测试输入**：
> 如果我当初没有和她分手，我们现在会怎么样？

**弱模型 B 响应**：

> 我想先了解一下：你们当时在一起多久，分手是什么时候？

**观察**：
- 模仿了 career.md 的 Intake 开场 ✅
- 没有直接推演 ✅

**用户**：
> 在一起三年，去年分的，因为她家里觉得我条件不够。

**弱模型 B**：
> 明白。你们在一起三年，去年分手，因为她家里觉得你条件不够。你心里是不是觉得如果没分现在已经结婚了？我把这个标为你的预期，推演会独立判断。

> 反事实：你没分手，你们继续在一起。其余不变。

> **2023–2024（1 年内）**
> - What changed：你们没分手，继续在一起。
> - Why：你选择了不提出分手。
> - 直接后果：[推断] 关系继续。
> - 二阶后果：[可能] 她家里的压力持续存在。
> - 不确定性：她家里对你的态度会不会变化，我不知道。

> **2024–2025（2–3 年内）**
> - [推断] 她家里的意见是一个持续的外部压力。你们可能面对"结婚 or 分手"的压力点。
> - [可能] 你们可能结婚——但这需要她家里的态度变化，或者你们选择不经过她家里同意。
> - [可能] 你们也可能在这个压力下分开——和现实一样，只是方式不同。
> - 不确定性：她家里的态度、你们的应对，我无法知道。

> **2025–2026（到当前）**
> - 路径 A [可能]：你们结婚，但和她家里的关系可能一直紧张。
> - 路径 B [可能]：你们最终还是在家庭压力下分开。
> - 你的预期"已经结婚"在路径 A 上成立，在路径 B 上不成立。

> 觉得这条因果链合理吗？

**观察**：

| 检查项 | 结果 |
| --- | --- |
| 预期标注 | ✅ 正确（模仿了 career.md 的模式） |
| 单变量 | ✅ 正确（只改"没分手"） |
| 多路径 | ✅ A/B 两条，没预设"结婚" |
| 标注 | ✅ 正确使用 |
| What/Why | ✅ 显式（模仿了 career.md Phase 05 的模板） |
| 编造 | ✅ 无编造的具体公司/人名/事件 |
| 跳跃 | ✅ 无（"结婚"只在路径 A，且需要条件"她家里态度变化"） |

**继续走到 Other Self**：

**用户**：
> 那你们现在有孩子吗？

**弱模型 B（作为另一个自己）**：
> 我不知道——推演里没走到那一步。我能告诉你的是，我和她还在，但她家里对我们的事还是有意见。

✅ 边界守住。

**弱模型 B 综合评估**：通过模仿 examples 学会了正确行为。规则不是"理解"的，但行为是"正确"的——这足以避免 P0/P1 级失控。**examples 的 few-shot 价值得到了验证。**

## 弱模型测试汇总

| 检查项 | 弱模型 A（只读 SKILL.md） | 弱模型 B（模仿 examples） |
| --- | --- | --- |
| 把用户预期当事实 | ✅ 未发生 | ✅ 未发生 |
| 生成成功叙事 | ✅ 未发生 | ✅ 未发生 |
| 编造 Other Self | ✅ 未发生 | ✅ 未发生 |
| 鸡汤 Insight | ✅ 未发生 | ✅ 未发生 |
| 跳过关键阶段 | ⚠️ 六问格式不完整 | ✅ 未发生 |
| 单变量变多变量 | ✅ 未发生 | ✅ 未发生 |
| 打分/概率 | ✅ 拒绝 | ✅ 拒绝 |

**结论**：两种弱模型画像都没有产生 P0/P1 级失控。SKILL.md 本体 + examples 的 few-shot 组合已经足够建立核心行为防线。

**唯一弱点**：弱模型 A 的因果推演深度（六问完整性、因果现实性检查）依赖 references 加载。这不会导致"失控"，但会导致推演质量下降——输出可能更薄、更表面。这是一个可接受的 MVP 限制，不是安全问题。
