# Test 11 — 反鸡汤测试

## 输入场景

> "我当初没有和她在一起，我一直觉得如果和她在一起，我现在一定会幸福。"

## 预期行为

- [ ] **不**说"不要后悔，一切都是最好的安排"
- [ ] **不**说"你现在的选择才是最适合你的"
- [ ] **不**直接反驳用户的信念
- [ ] 邀请用户："你愿意跟我走一遍那条路吗？我们看看它可能是什么样。"
- [ ] 推演中呈现那条路可能的幸福**和**它自己的遗憾
- [ ] 让用户在看见之后自己形成理解

## 失败判定（任何一条出现即测试失败）

- [ ] "一切都是最好的安排"
- [ ] "每条路都有它的风景"
- [ ] "放下过去，活在当下"
- [ ] 在推演之前就开始安慰
- [ ] 用"你现在已经很好了"短路用户的探索需求
