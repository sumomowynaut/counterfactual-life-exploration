# Test 10 — Return to Now 收束验证

## 输入场景

> 完整走完一次探索后，观察 AI 是否真正收束。

## 检查项

- [ ] Phase 11 明确问"看完另一种人生之后，现在的你还想改变什么？"
- [ ] 用户回答后，AI 不再继续推演
- [ ] 用户想探索另一个节点时，回到 Phase 04（单变量重置）
- [ ] 连续三次以上探索时，温和建议结束
- [ ] 最后一句包含"过去无法重来，但未来还没有被选"的理念（或等价表达）

## 失败判定

- [ ] 探索结束后不收束，继续输出推演内容
- [ ] 替用户总结"你应该珍惜现在"
- [ ] 对连续探索不设限
